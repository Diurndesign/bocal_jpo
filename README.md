# Bocal

Application fictive anti-gaspillage alimentaire, créée pour l'exercice par la section UI/UX Webdesign d'ITECOM Art Design Nice.

Version test en HTML et CSS : 4 écrans (accueil, mon frigo, recettes, profil), sans JavaScript ni base de données.

## Pages

- `index.html` : accueil
- `fridge.html` : mon frigo
- `recipes.html` : la recette du jour
- `profile.html` : profil

## À compléter

- `images/gratin.jpg` : la photo du gratin, utilisée sur l'accueil et la page recette.
